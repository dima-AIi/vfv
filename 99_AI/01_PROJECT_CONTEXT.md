# 01_PROJECT_CONTEXT.md

**Status:** Approved

**Version:** 2.1

## Purpose

Этот документ предоставляет краткий фактический контекст DevOS: назначение проекта, его границы и текущее состояние.

Он не определяет архитектуру, технологический стек, продуктовые требования или процесс разработки. За подробными и нормативными сведениями необходимо обращаться к профильным документам-владельцам.

## 1. Проект

DevOS — AI-First модульная SaaS-платформа для автоматизации внутренних бизнес-процессов компаний.

Платформа создаётся как единая экосистема бизнес-возможностей с общими инженерными принципами и рассчитана на постепенное долгосрочное развитие. Пользователь воспринимает DevOS как единый продукт, а внутреннее устройство разделяет ответственность между самостоятельными функциональными областями.

AI является инструментом разработки и сопровождения. Стратегические, продуктовые, архитектурные и security-решения остаются за человеком.

## 2. Цели верхнего уровня

DevOS развивается с ориентацией на:

- модульность;
- масштабируемость;
- сопровождаемость;
- предсказуемость изменений;
- документационно управляемую разработку;
- безопасное использование AI-инструментов.

Эти формулировки дают только общий контекст. Архитектурные ограничения определяются архитектурными документами, а состав продукта — Product Roadmap и MVP Specification.

## 3. Пользователи

Основные категории пользователей платформы:

- владельцы бизнеса;
- руководители;
- сотрудники;
- администраторы.

Документация также рассчитана на инженеров и AI-агентов, которые будут развивать и сопровождать проект.

## 4. Границы проекта

DevOS является модульной бизнес-платформой для внутренних процессов организаций.

DevOS не является:

- конструктором сайтов;
- CMS общего назначения;
- интернет-магазином;
- игровой платформой;
- социальной сетью;
- набором несвязанных экспериментальных функций.

Детальные границы продукта и MVP находятся в профильной продуктовой документации.

## 5. Текущее состояние

На момент завершения документационного pre-Git аудита:

- исследовательская документация создана;
- архитектурная документация создана;
- продуктовая документация создана;
- документы разработки созданы;
- AI Context Layer создан и консолидирован;
- корневой `AGENTS.md` создан и является операционным регламентом AI;
- нормативные документы разработки согласованы с local-first моделью и веткой `develop`;
- Master Documentation Index отражает полный фактический состав документации;
- кодирование DevOS ещё не начиналось;
- локальный Git-репозиторий ещё не создан;
- GitHub-репозиторий DevOS ещё не создан;
- локальный проект находится в `D:\Project_Zero\DevOS`;
- физическая структура проекта на этом этапе не изменяется;
- до `git init` остаются явно зафиксированные решения владельца и остаточные проверки из итогового pre-Git отчёта.

Инициализация Git и подключение приватного GitHub-репозитория выполняются только отдельной задачей после положительного pre-Git решения. Реализация первого модуля начинается позднее, после проверки работы Coding Agent и предреализационной готовности.
