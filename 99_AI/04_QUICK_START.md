# 04_QUICK_START.md

**Status:** Approved

**Version:** 2.0

**Category:** AI Bootstrap

## Purpose

Quick Start — короткая навигационная памятка для первого входа в DevOS.

Документ не заменяет корневой [`AGENTS.md`](../AGENTS.md), профильную документацию или процесс разработки.

## Первый вход

```text
Прочитать AGENTS.md
↓
Получить общий контекст в 99_AI/01_PROJECT_CONTEXT.md
↓
Определить профильные документы через 99_AI/02_ARCHITECTURE_INDEX.md
↓
При необходимости сверить терминологию с 99_AI/03_GLOSSARY.md
↓
Прочитать профильный документ-владелец
↓
Проверить готовность задачи по 03_DEVELOPMENT/15_Development_Workflow.md
```

## Перед началом задачи

Необходимо иметь проверяемые ответы на четыре вопроса:

1. Что требуется сделать?
2. Почему это требуется?
3. Какой документ является владельцем требования?
4. Что будет считаться готовым результатом?

Если задача требует архитектурного, продуктового, security-решения или иного согласования, предусмотренного `AGENTS.md`, реализация начинается только после решения человека и обновления профильной документации.
